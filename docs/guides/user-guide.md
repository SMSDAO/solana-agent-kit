# User Guide

## Getting Started

### 1. Connect Your Wallet

Visit the dashboard at your deployment URL (or `http://localhost:3000` locally).

Click **"Connect Wallet"** and choose your Solana wallet:
- **Phantom** — most popular browser extension wallet
- **Solflare** — multi-platform Solana wallet
- **Torus** — social login-based wallet
- **Ledger** — hardware wallet

Once connected, you will be redirected to your **User Dashboard**.

---

## User Dashboard

### Wallet Overview

The top stats panel shows:
- **SOL Balance** — your current SOL balance
- **Portfolio Value** — estimated USD value based on SOL price
- **Transactions** — transaction count
- **NFTs Owned** — NFT count in your wallet

### Token Holdings

The Token Holdings panel lists all SPL tokens in your wallet with mint addresses and balances.

### Transaction History

Recent transactions are displayed with:
- Transaction signature (truncated)
- Block time
- Status (Success / Failed)

### Quick Actions

- **Send SOL** — open a transfer dialog
- **Swap Tokens** — navigate to Jupiter-powered token swap
- **Stake SOL** — navigate to staking interface
- **View NFTs** — browse your NFT collection

## Navigation

The top navigation bar includes:

| Tab | Description |
|---|---|
| **Home** | Landing page |
| **Dashboard** | Your wallet overview |
| **Users** | User directory (admin-only) |
| **Admin** | Admin panel (admin-only) |
| **Developer** | Developer tools |
| **Settings** | Account settings |
| **Docs** | Documentation links |

---

## Settings

Access **Settings** from the navigation bar to:
- View your connected wallet address
- Switch Solana network (Mainnet / Devnet / Testnet)
- Disconnect wallet
- Manage notification preferences

---

## Security Tips

- Only connect wallets you own
- Never share your private key or seed phrase
- Use hardware wallets (Ledger) for large holdings
- Disconnect your wallet when done on shared devices
